# 🤖 TG Archiver — ربات آرشیو هوشمند تلگرام

رباتی که عکس/فایل می‌گیرد، **به‌صورت خودکار دسته‌بندی می‌کند** و در یک **کانال/گروه خصوصی**
ذخیره می‌کند. با **کنترل دسترسی چندحسابه** — فقط کاربران مجاز (allowlist) می‌توانند
فایل بفرستند یا دریافت کنند.

> ⚠️ امنیت: هرکسی که آیدی ربات را بداند **نمی‌تواند** وارد شود — فقط افرادی که
> `user_id` آن‌ها در allowlist است مجازند. افزودن کاربر از **خودِ ربات** و فقط توسط مالک.

---

## ✨ قابلیت‌ها

- 📥 دریافت عکس/فایل و دسته‌بندی خودکار با هوش مصنوعی (Vision AI)
- 📸 ثبت عکس به‌صورت **عکس واقعی** (نه فقط فایل) تا در آرشیو قابل مشاهده باشد
- 🗂️ ذخیره‌ی منظم در **زیرگروه‌های کانال** (forum topic به‌ازای هر دسته) + پوشه‌های محلی
- 🗄️ ذخیره‌ی منظم در کانال خصوصی (کانال = دیتابیس، message_id = شناسه)
- 📋 ثبت متادیتا در `index.json` (نوع، برچسب، تاریخ)
- 🤖 **تشخیص خودکار دسته** با کلید AI (Gemini / OpenAI) که از خودِ ربات تنظیم می‌شود
- 🤖 **تحلیل عکس** با هوش مصنوعی (`/analyze`)
- 🤖 **ایجنت‌های هوشمند** برای بازیابی (`/agents برام کارت ملیم رو بیار`)
- 🔍 جستجو و بازیابی: `برام کارت ملیم رو بیار`
- 👥 کنترل دسترسی چندحسابه با user_id (نه یوزرنیم!)
- ➕ افزودن/حذف کاربر از خودِ ربات توسط مالک

## 🚀 نصب و راه‌اندازی

### ۱) پیش‌نیازها
- Node.js 18+ (ترجیحاً از [Termux](https://f-droid.org/packages/com.termux/))
- یک کانال/گروه خصوصی (برای آرشیو)
- توکن ربات از [@BotFather](https://t.me/BotFather)

### ۲) کلون پروژه
```bash
git clone https://github.com/Saeed41144/tg-archiver.git
cd tg-archiver
```

### ۳) نصب وابستگی‌ها
```bash
npm install
```

### ۴) تنظیمات
```bash
cp .env.example .env
nano .env   # BOT_TOKEN ،CHANNEL_ID ،OWNER_ID
```

| متغیر | توضیح |
|-------|-------|
| `BOT_TOKEN` | توکن از @BotFather |
| `CHANNEL_ID` | شناسه عددی کانال آرشیو (مثل -100123456789) |
| `OWNER_ID` | user_id مالک اول (از @userinfobot بگیرید) |
| `AI_PROVIDER` | `gemini` (پیش‌فرض) / `openai` — اختیاری |
| `GEMINI_API_KEY` | کلید Gemini (یا با `/setai`) |
| `OPENAI_API_KEY` | کلید OpenAI (یا با `/setai openai`) |

> 🔑 کلید هوش مصنوعی را می‌توانید از **خودِ ربات** و بدون ویرایش فایل تنظیم کنید:
> `/setai <کلید Gemini>` یا `/setai openai <کلید>`.
> کلید در `data/ai.json` ذخیره می‌شود و **هیچ‌وقت در GitHub نمی‌رود**.

> 💡 یوزرنیم را نمی‌گذارید، **user_id عددی** را می‌گذارید — امن‌تر است.
> کاربران بعدی را از داخل ربات با `/adduser @username` اضافه می‌کنید.

### ۵) اجرا
```bash
npm start
```

## 📖 دستورهای ربات

| دستور | دسترسی | کار |
|-------|--------|-----|
| `عکس/فایل ارسال کن` | همه مجازها | ذخیره + دسته‌بندی خودکار |
| `/analyze` (با عکس) | همه مجازها | تحلیل عکس با هوش مصنوعی |
| `/get <شناسه>` | همه مجازها | دریافت فایل |
| `/search <کلیدواژه>` | همه مجازها | جستجو در آرشیو |
| `/agents <عبارت>` | همه مجازها | بازیابی با ایجنت هوشمند |
| `/stats` | همه مجازها | آمار آرشیو |
| `/setai <کلید>` | فقط مالک | تنظیم/حذف کلید AI (`/setai off`) |
| `/adduser @username` | فقط مالک | افزودن کاربر |
| `/removeuser @username` | فقط مالک | حذف کاربر |
| `/listusers` | فقط مالک | لیست کاربران |
| `/help` | همه | راهنما |

## 🔐 امنیت (مهم)

- **فقط user_id عددی** در allowlist ذخیره می‌شود؛ یوزرنیم قابل عوض شدن است، user_id نه.
- کانال آرشیو باید **Private** باشد.
- دستورهای حساس (`/adduser` و...) فقط روی **user_id مالک** کار می‌کنند.
- `.env` را **هرگز** کامیت نکن (در `.gitignore` است).
- هر کاربر اضافه/حذف‌شده، خودش در ربات `✅` تأیید می‌گیرد.
